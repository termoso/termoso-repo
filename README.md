# Termoso package repositories

APT and DNF repositories for [Termoso](https://termoso.dev), regenerated by the
[release workflow](https://github.com/rep0rtDev/termoso/blob/main/.github/workflows/release.yml)
on every release. Install instructions: https://rep0rtdev.github.io/termoso-repo/

Do not edit by hand — changes are overwritten by the next release.
